# Fake News Detection with GenAI 📰❌

This project implements a **Fake News Detection system** using **Python** and **Machine Learning**.  
The model classifies news text as **Real News 📰** or **Fake News ❌** using TF-IDF and Logistic Regression.

---

## 🚀 Features

- Text preprocessing using TF-IDF
- Binary classification (Real vs Fake)
- Machine learning model using Logistic Regression
- Model persistence using Pickle
- Simple and beginner-friendly implementation

## 📊 Dataset

- File: `data/fake_news.csv`
- Columns:
  - `text` → News content
  - `label` → `1` = Real News, `0` = Fake News
